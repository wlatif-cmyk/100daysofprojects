# Arduino Project Generator

This is a small, self-contained web app that suggests Arduino projects and gradually increases difficulty each time you pull a new project.

Features
- Clean, minimal UI
- "Pull a project" animation that comes out of a magician's hat
- Confetti effect when a project is revealed
- Difficulty level that increases gradually

How to run
1. Open `arduino-project-generator/index.html` in your browser (double-click or use your browser's Open File...).
2. Click "Pull project" to reveal a new Arduino project. Use Reset to start over.

Notes
- No build or server required — it's a simple static page.
- The project list is in `script.js` and can be edited to add more ideas or change difficulty ratings.
